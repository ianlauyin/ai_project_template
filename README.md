# AI agent docs template

Agent-facing documentation extracted from [ianlauyin/pri_festa_workspace](https://github.com/ianlauyin/pri_festa_workspace). These files tell an AI coding agent how this kind of repo is structured, how to write specs, and which rules to follow before editing, committing, and updating specs.

Product names from Pri Festa remain in the copied docs so the original paths and cross-references stay intact.

## Included

- `AGENTS.md`
- `spec/00_structure.md`
- `spec/writing-specs.md`
- `spec/rules/coding-style.md`
- `spec/rules/git-convention.md`
- `spec/rules/spec-update.md`

## Excluded

Wedding product specs were left in the source repo: `spec/dashboard/`, `spec/rsvp/`, `spec/shared/`, `spec/db.md`, and `spec/deployment.md`, along with application code, UI, assets, and unrelated config.

No LLM, prompt, or orchestration product docs existed in the source beyond these agent docs. `spec/rules/spec-update.md` mentions `skills/write-spec.md`, which was not in the source repo and is not included here.
